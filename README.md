# Apps for Fun and Games

## Run locally
1. Extract this ZIP.
2. Open the `apps-fun-games` folder in VS Code.
3. Open `index.html` with the VS Code Live Server extension (or open it directly in a browser).
4. Select **START ACTIVITY** to open `game.html`.

## Gameplay
- Sort the apps into **Fun**, **Learn**, **Create**, or **Talk**.
- Select an app card and tap a category, or drag the card onto a category.
- Correct answers earn 100 points and animate into the matching category.
- Incorrect answers stay in the tray and shake to give feedback.
- The next wave starts automatically when the current wave is complete.
- Complete all 3 waves (10 apps) to see the result screen and confetti.

## Wave contents
- Wave 1: Snakes & Ladders, Times Tables, Sketchbook, Video Call
- Wave 2: Beat Maker, Kids Mail, Jigsaw Mania
- Wave 3: Photo Filter, Voice Chat, Arcade Race

No build tools or npm packages are required. This is a plain HTML/CSS/JavaScript project.
